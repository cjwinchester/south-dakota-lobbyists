# South Dakota lobbyist data

This repository is archived. South Dakota's lobbyist registrations are published as CSV files at [south-dakota-citizen-archivist/sd-archive › releases › Lobbyist data](https://github.com/south-dakota-citizen-archivist/sd-archive/releases/tag/lobbyists-data):

- **lobbyists-private.csv**: private lobbyist registrations from 2012 on, one per lobbyist, employer and year, read from each registration's detail page, with names and addresses split into parts
- **lobbyists-private-filings.csv**: the filings listed on each registration, with links
- **lobbyists-public.csv**: public lobbyists, one per lobbyist, agency and year

Registrations the Secretary of State no longer lists stay in those files, marked with the date they were first missed.

The files here are as of March 16, 2026: [`private/south-dakota-lobbyists-private.json`](private/south-dakota-lobbyists-private.json) (10,189 private registrations) and [`public/south-dakota-lobbyists-public.csv`](public/south-dakota-lobbyists-public.csv) (5,494 rows, which repeat 136 year, name and agency combinations).
